## 性能

原始数据见 results.json。300 个 UTF-8 文件，每文件 31 行，30 轮稳定调用；不含 MCP 网络时间。

| 场景 | 关闭记录 P50 | 开启记录 P50 | Python pathlib 对照 P50 |
| --- | ---: | ---: | ---: |
| 文件查找 | 75.19 ms | 89.96 ms | 1.72 ms |
| 文本搜索 | 67.74 ms | 84.12 ms | 21.80 ms |

此样本中记录增加约 15–16 ms 中位耗时，不能称为可忽略。小目录下 Python 对照更快，不能据此宣称 fastsearch 全面提速，也不能推广到大型项目。查询结果已核对一致。

日志使用 SQLite WAL + NORMAL 同步模式；系统突然断电时最近事务可能丢失。日志不用于业务状态恢复。
